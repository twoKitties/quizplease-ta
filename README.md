# quizplease-ta - «Energy & Regen» (реактивный сервис + UI)

Тестовое задание: Сделай систему энергии для мобильной игры.

## Стек

- **Unity 6000.4.0f1**
- **VContainer**
- **UniTask**

## Как запустить

1. Открыть проект в **Unity 6000.4.0f1**.
2. Открыть сцену `Assets/Project/Scenes/Game.unity`.
3. Убедиться, что на сцене есть объект с `RootLifetimeScope` (точка сборки DI).
4. Нажать **Play** в редакторе.

Энергия стартует полной (`N / N`), клик по кнопке тратит энергию, дальше энергия восстанавливается раз в `RegenSeconds`. Параметры настраиваются в `Assets/Project/Settings/EnergySettings.asset`.
